# Contributing to Laravel Pro Docs CLI

Thank you for considering contributing to the Laravel Pro Docs CLI tool! 

## Getting Started

1. Fork the repository on GitHub.
2. Clone your fork locally: `git clone https://github.com/<your-username>/laravel-pro-docs.git`
3. Install dependencies: `composer install`

## Running Tests

All changes must pass the test suite. To run the tests locally:

```bash
composer test
```

## Pull Request Process

1. Ensure all tests pass.
2. Update the README.md with details of changes to the CLI interface, if applicable.
3. Submit a pull request. We will review your changes as soon as possible.
